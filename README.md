# Vajra Flow · 金剛經記憶小卡 (PWA)

> **應無所住，而生其心。**  
> 《金剛般若波羅蜜經》科學記憶小卡與原聲誦念 Progressive Web App。

---

## 🌟 核心特色

1. **經文嚴謹對齊**：
   * 全卷 32 分、63 張背誦小卡，100% 嚴格校勘對齊經典版本。
2. **科學溫故知新排程**：
   * 內建艾賓浩斯（Ebbinghaus）記憶複習排程：5分鐘、30分鐘、12小時、1天、2天、4天、7天、15天。
   * 一列式精簡膠囊設計，支援在設定中一鍵顯示或隱藏，為經文保留最純淨閱讀空間。
3. **高品質神經原聲念誦（支援螢幕休眠 / 背景鎖屏播放）**：
   * **👨 男生念誦**：微軟神經自然原聲（雲揚），聲線莊嚴渾厚、深沉定心。
   * **👩 女生念誦**：微軟神經自然原聲（曉臻），台灣溫潤正音、清淨慈悲。
   * **背景播放與鎖屏控制 (MediaSession API)**：手機關閉螢幕、切換 App 均不中斷；支援鎖定畫面上下翻卡與暫停播放。
4. **極致舒適的護眼閱讀體驗**：
   * **字體隨選**：經典楷體、宋體/細明體、清晰黑體。
   * **字級調整**：小 (20px)、標準 (24px)、大 (28px)、特大 (32px)。
   * **行距調校**：緊湊 (1.4)、舒適 (1.7)、寬鬆 (2.0)、超寬 (2.3)。
   * **行雲流水絲滑翻卡**：外框穩如磐石，內文微滑動淡入，告別突兀彈跳感。
5. **手勢操作與進度安全快取**：
   * 支援手機左右滑動翻卡（👉 向左滑下一卡，👈 向右滑上一卡）。
   * SafeStorage 防禦性快取機制，雙擊開啟 `file:///` 亦可安全降級運行。
